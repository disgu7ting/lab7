## Используемые jQuery-функции
- `$(document).ready()` – ожидание загрузки DOM.
- `$('.tab-btn').click()` – обработка клика по вкладкам.
- `.addClass()`, `.removeClass()`, `.toggleClass()` – управление классами.
- `$.get()` – AJAX-запрос для получения цитаты.
- `$('#draggable').draggable()` – перетаскивание элемента через jQuery UI.
- `$('#datepicker').datepicker()` – подключение календаря.

---

## Сравнение jQuery и Vanilla JS
- jQuery обеспечивает **короткий, удобный и кроссбраузерный код**, особенно полезен для легаси-проектов и работы с плагинами.  
- Vanilla JS более современный, не требует сторонних библиотек, лучше оптимизирован для современных сайтов.

---

## Что оставить для современного сайта
Для нового проекта на сегодняшний день **Vanilla JS** предпочтительнее:
- Плавная прокрутка и работа с DOM легко реализуются нативными методами.  
- AJAX-запросы через `fetch` проще и современнее.  
- jQuery стоит использовать только при необходимости работы с **легаси-кодом** или готовыми плагинами.
